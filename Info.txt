BLOQUEO CONEXION REMOTA

Ese error es de seguridad de Windows — bloqueó tu usuario por demasiados intentos fallidos de contraseña. Pasa frecuentemente cuando usas escritorio remoto.
Solución desde la consola de AWS:

Ve a AWS Console → EC2 → Instancias
Selecciona tu instancia → clic en Conectar
Usa EC2 Instance Connect o Session Manager para entrar sin contraseña
Una vez dentro, abre PowerShell como administrador y ejecuta:

powershell# Desbloquear el usuario (reemplaza "usuario" con tu nombre de usuario)
net user usuario /active:yes

# O si está bloqueado por intentos fallidos:
net accounts /lockoutthreshold:0
Si no tienes Session Manager configurado, otra opción es:

En AWS Console ve a tu instancia
Acciones → Monitoreo y solución de problemas → Obtener contraseña de Windows
Usa tu key pair (.pem) para descifrar la contraseña
Intenta conectarte con esa contraseña

Para evitar que pase de nuevo, una vez que entres ejecuta esto en PowerShell:
powershell# Deshabilitar bloqueo por intentos fallidos
net accounts /lockoutthreshold:0
